# 모의 데이터 설계와 재현 코드

이 블로그의 차트는 모두 **모의 데이터(가상)**다. 실제 통계가 아니며, 개념과 방향을 보여 주려고 만든 값이다. 아래 코드(파이썬, numpy·pandas)를 그대로 실행하면 같은 수치와 차트가 다시 나온다(시드 20261121).
